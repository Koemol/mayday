# Mayday · 银河自传

五月天非官方歌迷视觉阅读页面。保留原项目七首歌及其全部歌词片段，改为温暖、梦幻的可滚动情绪画廊。没有音频播放器。

## 本地预览

在此目录运行 `python -m http.server 8765 --bind 127.0.0.1`，浏览器打开 http://127.0.0.1:8765 。也可以使用任意静态服务器。不要直接用 file:// 打开，因为浏览器会限制 JavaScript 模块加载。

## 文件

- `index.html`：首页、画廊、原生 dialog 歌词阅读器。
- `styles.css`：1700px 最大版心、三列桌面/双列手机布局、玻璃材质和减少动态效果支持。
- `app.js`：情绪筛选、七首歌切换、逐句阅读、暂停、随机漫游、后台暂停计时器。
- `songs.js`：保留原项目的歌曲数据，歌词版权归原权利人所有。
- `assets/`：本地 WebP 主视觉与海面图片，无远程图片或字体依赖。

## 设计与性能

奶油白、鼠尾草绿、暖黄；衬线大标题、错落图像画廊、玻璃心情卡片。以轻量 CSS 动画取代原本的 Three.js 五万粒子循环。桌面主图约 234 KB，手机主图约 61 KB，海面图约 52 KB；首屏图片优先加载，画廊图片懒加载。不使用外部运行时、字体或追踪服务。

## 验证

在 Codex 内置浏览器实际检查 320、390、768、1440、1920px 视口；无水平溢出，1920px 下版心为 1700px。已检查情绪筛选、歌词弹窗、换句、换歌、暂停和 Esc 关闭。浏览器未报告错误。未在真实 iOS/Android 设备上进行性能评分测试。

## 部署

纯静态站点，无需构建。将 index.html、styles.css、app.js、songs.js 和 assets/ 一起发布到静态托管目录。所有资源使用相对路径，支持 GitHub Pages 的 /mayday/ 子路径。分支提交或 PR 本身不代表已部署，实际发布取决于仓库的托管配置。

## 图像来源

两张原创图像使用内置 imagegen 生成，并以 sharp 导出 WebP。完整提示词见 `IMAGE-PROMPTS.md`。其他装饰为 CSS 绘制。
